# News-Classifier-NLP
A deep learning–based News Classification web application built using PyTorch for model training and Flask for deployment. The model classifies news articles into predefined categories using a supervised learning approach.

## Project Overview
This project demonstrates an end-to-end Machine Learning pipeline:
- Data preprocessing and analysis using NumPy and Pandas
- Data visualization using Matplotlib
- Traditional ML utilities from Scikit-learn
- Deep learning model implementation using PyTorch
- Model deployment via Streamlit

**The final model achieves 88.94% test accuracy after 10 training epochs.**

### Tech Stack
- NumPy – Numerical computations
- Pandas – Data manipulation and preprocessing
- Matplotlib – Visualization of training metrics
- Scikit-learn – Data splitting and evaluation metrics
- PyTorch – Neural network implementation and training
- Streamlit – Web application deployment
